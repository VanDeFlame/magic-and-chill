# Magic & Chill

## Description
De momento no es más que un simple canvas en el que unos personajes se mueven sin un propósito, simplemente se les asigna una lista de tareas aleatorias a realizar.

## Installation

1. Instalar dependencias ejecutando `npm i`.
2. Levantar el proyecto ejecutando `npm run dev`.
3. Acceder, mediante el navegador, a `http://localhost:3000`.
4. Eso es todo. No hay más.
